# 数据源清单（按司法辖区）— company-due-diligence

> 原则：**公开网页能自动抓的走脚本（L1 百度/Bing），需验证码/登录的进 manual_required 清单**，
> 人工核验入口永远写在报告里。下表标注了每个源的接入方式。

## 🇨🇳 中国大陆（求职背调主战场）

| 数据源 | 用途 | 接入方式 | 说明 |
|---|---|---|---|
| 百度搜索 (baidu.com/s) | 综合线索：新闻/欠薪/仲裁/招聘 | ✅ L1 脚本主引擎 | curl_cffi 指纹，命中率高（实测 1.07MB/9 标题） |
| 爱企查 aiqicha.baidu.com | 工商面板：法定代表人/注册资本/成立时间/状态 | ⚠️ 面板可自动解析；详情页 wappass 验证码 | 脚本自动抽"企业信息面板"，详情页给链接人工看 |
| 国家企业信用信息公示系统 gsxt.gov.cn | 经营异常名录/严重违法/行政处罚/年报 | 🔒 验证码+登录 | 永远进 manual_required |
| 中国执行信息公开网 zxgk.court.gov.cn | 被执行人/失信/限制消费 | 🔒 验证码 | 红线 1 主渠道 |
| 信用中国 creditchina.gov.cn | 行政处罚/失信惩戒/欠税 | ⚠️ 部分公开 | 红线 1/7 辅助 |
| 裁判文书网 wenshu.court.gov.cn | 判决书（劳动仲裁/诉讼） | 🔒 登录+验证码 | 红线 4/6 主渠道 |
| 中国庭审公开网 | 开庭公告 | ⚠️ 可搜 | 红线 6 辅助 |
| 各地人社局官网 | 重大劳动保障违法/欠薪黑名单公告 | ⚠️ 人工搜索 | 红线 3/7 主渠道 |
| 天眼查/企查查 | 工商变更/司法案件汇总 | 🔒 付费或登录 | 红线 5/6 便捷入口 |
| 看准网/职友集 | 员工评价 | ⚠️ 反爬强 | reviews 命令只给链接 |
| 脉脉/知乎/小红书/BOSS直聘评论 | 员工真实评价 | ⚠️ 反爬强 | 需 L2/L3 或人工 |

## 🌍 境外公司（global-mode）

| 数据源 | 辖区 | 用途 | 接入方式 |
|---|---|---|---|
| OpenCorporates | 全球 140+ 辖区 | 注册主体/成立日期 | ⚠️ 公共 API 常 401；设 `OPENCORPORATES_API_KEY` 后脚本自动用 |
| Bing 搜索 | 全球 | 综合线索 | ✅ L1 脚本（境外公司主引擎，建议 `--engines bing,baidu`） |
| SEC EDGAR | 🇺🇸 美国 | 上市公司财报/诉讼/处罚 | ⚠️ 人工（data.sec.gov 可脚本化，暂未内置） |
| 各州 SOS 官网 | 🇺🇸 美国 | 注册状态/解散/罚单 | 🔒 分州系统，人工 |
| Companies House | 🇬🇧 英国 | 注册/清算/处罚 | ⚠️ 免费 API 可查（find-and-update.company-information.service.gov.uk） |
| ACRA | 🇸🇬 新加坡 | 注册/董事 | 🔒 付费，人工 |
| 公司注册处 CR | 🇭🇰 香港 | 注册/清盘 | ⚠️ 可网上查册，人工 |
| ABR/ASIC | 🇦🇺 澳大利亚 | ABN/注册状态 | ⚠️ 公开查询，人工 |
| 各国劳动法院/仲裁公开库 | 各国 | 劳动争议 | 人工（搜 `{公司名} labor dispute / unfair dismissal`） |

## 境外公司快速人工核验模板（写给用户）

1. `{公司名} + lawsuit / sued / judgment`（诉讼）
2. `{公司名} + wage theft / unpaid wages`（欠薪）
3. `{公司名} + layoff / redundancy`（裁员）
4. OpenCorporates 查注册主体与状态 → 区分"品牌"与"注册主体"
5. 员工评价：Glassdoor / Indeed / Blind（英文）；看准/脉脉（中文外企评价）
